养生助手 App

使用说明文档
HarmonyOS v1.0 用户/医生/管理员 三端

一、App简介

养生助手是一款基于 HarmonyOS 的智能健康管理应用，围绕中医养生理念，结合天气环境、个人体质和健康档案，通过 AI 提供个性化的养生建议。

核心能力包括：AI 养生问答、中医体质问卷、舌象记录、健康指标管理、天气养生联动、在线问诊、积分商城等。

App 支持三种角色：普通用户 医生 管理员，每种角色有不同的功能界面。

二、安装与启动

2.1 前置条件

  • HarmonyOS 手机（建议系统版本 6.0 以上）
  • 后端服务已启动（默认端口 8181）
  • 手机和后端电脑在同一局域网（WiFi）下

2.2 安装 App

  1. 在 DevEco Studio 中打开项目，连接手机
  2. 点击 Run 编译安装
  3. 安装完成后手机桌面出现"养生助手"图标

2.3 配置后端地址

首次使用需要配置后端服务地址，确保 App 能连接到后端。

1
打开 App

进入登录页面

2
找到"服务器连接设置"

在登录页面最底部，灰色小字按钮

3
输入后端地址

格式：http://电脑IP:8181，例如 http://172.20.10.3:8181

4
点击"保存并测试连接"

显示"服务器连接成功"即可

如何查看电脑 IP
电脑打开 PowerShell，输入 ipconfig，找到"IPv4 地址"对应的值。手机和电脑必须连接同一个 WiFi。

3.2 密码登录

  1. 输入 11 位手机号
  2. 输入密码（至少 6 位）
  3. 点击"登录"按钮

3.3 验证码登录

  1. 点击顶部"验证码登录"切换模式
  2. 输入手机号
  3. 点击"获取验证码"，收到 6 位验证码
  4. 输入验证码，点击"登录"
开发环境验证码
开发模式下，验证码会直接显示在页面上（如"验证码已发送，开发验证码：123456"），无需真实短信。

3.4 注册新账号

  1. 点击底部"没有账号，去注册"
  2. 输入手机号、密码（至少 6 位）、确认密码
  3. 选择身份：普通用户 或 医生入驻
  4. 点击"获取验证码"获取验证码
  5. 输入验证码，点击"注册并进入"

3.5 忘记密码

  1. 点击底部"忘记密码"
  2. 输入手机号或账号，点击"下一步验证身份"
  3. 获取短信验证码并输入
  4. 输入新密码（至少 6 位）并确认
  5. 点击"修改密码"，用新密码登录

四、首次引导页

首次登录后会显示引导页，介绍 App 的核心功能。可以点击"下一步"逐步查看，或点击"跳过"直接进入主界面。引导页仅在首次登录后显示。

5.1 首页

首页是核心信息聚合页，展示以下内容：

  • 天气养生卡片：显示当前城市、温度、湿度、天气状况和养生建议（如"湿热提醒：健脾祛湿"）
  • 节气信息：当前节气名称、饮食建议和起居建议
  • 养生计划：根据天气和体质生成的三时段计划（上午/下午/晚上）
  • AI 建议：结合天气和体质的智能养生建议
  • 快捷入口：底部有"体质问卷"和"舌象记录"两个快捷按钮

使用体质问卷

  1. 点击首页底部的"体质问卷"快捷按钮
  2. 依次回答问卷题目（每题有多个选项，不同选项对应不同分值）
  3. 提交后系统计算总分，判定你的体质类型（如平和质、气虚质、阳虚质等）
  4. 体质结果会自动保存，并影响后续 AI 建议的方向
为什么要做体质问卷？
AI 助手会根据你的体质类型提供针对性的养生建议。建议首次使用时先完成问卷。

记录舌象

  1. 点击首页底部的"舌象记录"快捷按钮
  2. 填写舌质颜色（淡红/红/绛等）、舌苔（薄白/厚腻等）、干燥程度、备注
  3. 点击保存，舌象记录会纳入健康档案

5.2 AI 助手

AI 助手是一个智能养生问答对话界面，可以像聊天一样向 AI 提问。

使用方法

  1. 点击底部"助手"Tab
  2. 在底部输入框输入你的养生问题（如"最近总是失眠怎么办？"）
  3. 点击发送，等待 AI 回复（通常几秒内）
  4. AI 回复包含：文字回答、养生建议列表、三时段计划、风险等级
注意事项
  • 每次 AI 问答会消耗一定积分，请合理使用
  • AI 回复末尾包含免责声明："本建议不能替代医生诊断"
  • 如果涉及严重症状（胸痛、呼吸困难等），系统会提示及时就医
  • AI 回复会结合你的体质、天气、舌象、健康指标等个性化生成

5.3 在线问诊

可以向医生发起一对一问诊，获取专业建议。

发起问诊

  1. 点击底部"问诊"Tab
  2. 点击"发起问诊"按钮
  3. 填写问诊标题、主要症状、详细描述
  4. 提交后等待医生回复

查看和回复

  1. 在问诊列表中点击一条问诊进入详情
  2. 可以查看医生回复，并发送新消息
  3. 医生可以查看你的健康档案，辅助了解你的身体状况

5.4 健康档案

档案页集中展示你的所有健康数据，点击底部"档案"Tab进入。

模块功能
体质记录查看历次体质问卷结果和体质倾向
健康指标添加/查看血压、血糖、心率等指标记录，支持状态判断
舌象记录查看历次舌象观察记录
提醒设置设置健康提醒（如定时喝水、按时作息），系统通过本地通知推送
建议摘要基于档案数据生成的综合养生建议

添加健康指标

  1. 在档案页点击"添加指标"
  2. 输入指标名称（如"血压"）、数值、单位（如"mmHg"）
  3. 保存后系统会自动判断指标状态（正常/偏高/偏低）

设置健康提醒

  1. 在档案页找到"提醒设置"
  2. 点击添加提醒，填写标题（如"喝水"）和时间（如"09:00"）
  3. 开启提醒开关
  4. 系统会在设定时间通过手机通知推送提醒

5.5 我的

个人中心页面，包含以下功能：

  • 个人信息：查看和编辑头像、昵称、性别、年龄等
  • 积分账户：查看积分余额、每日签到、积分流水
  • 积分商城：浏览商品、用积分兑换
  • 退出登录：清除登录状态返回登录页

每日签到

  1. 进入"我的"页面
  2. 点击"每日签到"按钮
  3. 签到成功后获得积分奖励

积分兑换商品

  1. 在"我的"页面进入积分商城
  2. 浏览可用商品列表
  3. 选择商品点击兑换（需积分充足）
  4. 兑换后在订单列表中查看状态

八、常见问题

Q1：提示"后端响应超时"

可能原因及解决方法：

  • 后端未启动：确认 Spring Boot 后端（8181端口）已启动
  • IP地址不对：在登录页底部"服务器连接设置"中修改为正确的电脑 IP
  • 不在同一WiFi：确保手机和电脑连接同一个 WiFi 网络
  • 防火墙拦截：临时关闭电脑防火墙测试，或放行 8181 端口

Q2：AI 助手回复很慢或无回复

  • AI 问答超时时间设为 90 秒，复杂问题可能需要等待
  • 检查后端是否配置了 DeepSeek API Key
  • 积分不足时无法使用 AI 问答，请先签到获取积分
  • 后端 AI 服务不可用时会显示兜底回复

Q3：登录提示"登录已过期"

Token 有效期为 7 天，过期后需要重新登录。退出 App 重新打开也会自动校验登录状态。

Q4：天气信息不显示

  • 检查是否授予了定位权限（设置 → 应用 → 养生助手 → 权限）
  • 确保手机定位服务已开启
  • 天气服务支持多地址自动重试，如都失败会显示兜底天气数据

Q5：健康提醒不推送

  • 检查是否授予了通知权限
  • 确保手机未开启免打扰模式
  • 在档案页的"提醒设置"中确认提醒开关已开启

Q6：体质问卷结果不准确

体质问卷基于中医九种体质分类，结果仅供参考。建议如实回答，多次填写取最近一次结果。体质结果会随 AI 建议方向调整。

Q7：如何修改密码

在登录页点击"忘记密码"，通过手机号验证码重置密码。

Q8：医生如何查看用户健康档案

在问诊详情页，医生可以查看该用户的体质、健康指标、舌象记录等健康档案信息，辅助诊断。

九、注意事项

重要提示
  • AI 建议仅供参考：AI 生成的养生建议不能替代专业医生诊断，若症状持续或加重请及时就医
  • 紧急风险提示：如果 AI 检测到紧急风险信号（如胸痛、呼吸困难），会提示及时就医，不会自行给出建议
  • 积分消耗：AI 问答会消耗积分，每日签到可获取积分
  • 数据安全：健康数据存储在本地和后端数据库，登录信息通过 Token 加密传输
  • 网络依赖：大部分功能需要网络连接，断网时仅可查看本地存储的档案数据
