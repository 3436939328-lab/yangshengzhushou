# 养生助手 APP 上线检查清单

更新时间：2026-06-27

## 当前结论

- APP 主流程已经进入上线前完善阶段，三种身份保留为普通用户、医生、管理员。
- 当前 APP 默认连接 SpringBoot 后端：`http://172.20.10.10:8181`。
- Node.js 的 LLM、Prompt、LangGraph 能力采用 SpringBoot 代理/桥接方式接入，上线第一版建议保持 SpringBoot 统一对外、Node 仅作为内网 AI 编排服务。
- PC 端暂缓，先保证 APP 真机闭环。

## 启动顺序

1. 启动 SpringBoot 后端：`D:\SpringBoot\SpringBootDemo`，端口 `8181`。
2. 如本机仍保留 Node 编排服务，确认 SpringBoot 的 AI 编排配置能访问 Node 服务。
3. 手机和电脑连接同一网络，确认手机可以访问电脑 IP 的 `8181` 端口。
4. APP 中后端地址应填写电脑局域网 IP，例如 `http://192.168.1.8:8181`。
5. 运行真机 APP，先登录，再验证定位、天气、健康数据、问诊和管理员页面。

## 上线前必须通过的 APP 流程

### 账号与角色

- 注册时只能选择：普通用户、医生、管理员。
- 普通用户登录后进入普通用户页面。
- 医生登录后进入医生页面。
- 管理员登录后进入管理员页面。
- 登录过期或后端返回 `401` 时，APP 应清理会话并回到登录页。

### 定位与天气

- 首次进入时弹出定位权限。
- 系统定位关闭时提示“系统定位待开启”。
- APP 定位权限关闭时提示“定位权限待开启”。
- 获取到坐标后，天气接口返回当前城市、温度、湿度、天气建议。
- 当前位置应接近真实位置，不能固定显示上海、杭州等默认城市。

### 健康档案

- 普通用户可以保存体质问卷。
- 普通用户可以保存健康指标。
- 普通用户可以保存舌象文字记录。
- 数据页和我的页面应显示当前登录用户自己的记录。
- 切换账号后，不能看到上一个账号的本地聊天和健康档案缓存。

### 养生助手

- 聊天框高度固定，历史内容可滚动。
- 发送问题后优先调用 SpringBoot `/api/ai/chat`。
- 问答记录应写入后端数据库，管理员可以查看总记录。
- 后端不可用时，APP 应显示明确错误或本地兜底，不应假装已联网成功。
- 后端已对 `/api/ai/chat` 和 `/api/ai/suggestions` 增加基础限流，超限返回 `429`。
- 后端已限制单次 AI 问题最长 1000 字。

### 一对一问诊

- 普通用户可以通过下拉框选择已注册并完善资料的医生。
- 普通用户和医生都在统一聊天框 UI 内查看问诊消息。
- 医生只有在用户发起问诊后才看到会话。
- 医生登录时，如有待回复问诊，应先提醒。
- 管理员问诊总览应显示真实问诊总数、待回复数、进行中数量。

### 管理员

- 管理员总览顶部统计应来自后端真实数据。
- 人员列表筛选普通用户、医生、管理员时，只显示对应角色。
- 管理员可以新增、编辑、删除人员。
- 后端已限制用户、角色、用户角色管理接口为管理员可用。
- 管理员问答记录顶部统计应显示真实记录数量。
- 管理员点击某个人的问答记录后，再弹出该人的问答详情。
- 管理员问诊总览应显示真实问诊数据。

## 发布配置必须项

- `AppScope/app.json5` 中 `bundleName` 已暂定为 `com.ruange.health`，正式提交应用市场前仍需确认是否使用该包名。
- `AppScope/app.json5` 中 `vendor` 已暂定为 `ruange`，正式提交应用市场前仍需确认主体名称。
- `AppScope/app.json5` 中 `versionCode` 每次发布必须递增。
- `build-profile.json5` 需要配置正式签名，当前 `signingConfigs` 为空。
- 默认后端地址上线前不能使用局域网 IP，应切换为 HTTPS 域名。
- 后端全局异常统一 JSON 返回基础版已完成，生产日志文件滚动基础版已完成；上线前仍需要继续配置跨域、数据库备份和异常告警。

## 推荐真机回归顺序

1. 注册普通用户、医生、管理员各一个账号。
2. 医生登录，完善医生资料。
3. 普通用户登录，授权定位，查看天气温湿度。
4. 普通用户保存体质问卷、健康指标、舌象记录。
5. 普通用户进入养生助手，发送一条问题。
6. 普通用户进入一对一问诊，选择医生并发送问题。
7. 医生登录，确认收到问诊提醒并回复。
8. 管理员登录，查看人员统计、问答记录、问诊总览。
9. 管理员编辑、删除测试账号，确认数据库和 UI 同步。
10. 重启 APP，确认登录态、数据缓存、后端数据仍正常。

- SpringBoot 生产日志基础版已完成，`prod` 环境会写入 `logs/ruange-app.log` 和 `logs/ruange-error.log` 并自动滚动。
