# 茹安阁 — 参赛作品简介

## 作品名称
**茹安阁** — 基于 HarmonyOS 的智能中医健康养生平台

## 一句话介绍
融合 AI 舌象分析、个性化养生建议、在线问诊与亲人关怀的全场景健康管理应用。

---

## 作品概述

茹安阁是一款面向全年龄段用户的智能健康养生管理应用，基于 HarmonyOS 分布式操作系统与 Spring Boot 后端架构，融合人工智能、大数据分析与传统中医养生理念，为用户提供全方位、个性化的健康管理服务。

应用围绕"**测—评—养—医—护**"五大核心环节，构建了完整的健康管理闭环：

- **测** — 支持血压、血糖、心率、睡眠、体重、BMI 等 10+ 种健康指标的结构化记录
- **评** — AI 智能评估健康状态，舌象照片自动分析，生成健康卡与异常提醒
- **养** — 基于个人健康数据与 RAG 知识库，生成每日个性化养生建议
- **医** — 在线图文问诊，医生端工作台，健康快照一键共享
- **护** — 亲人关怀模块，家庭成员健康数据共享，授权管理，实时守护

---

## 核心功能亮点

### 1. AI 舌象智能分析
- 用户上传舌象照片，AI 自动识别舌质、舌苔特征
- 基于中医舌诊理论给出健康参考与养生建议
- 历史舌象对比，跟踪健康变化趋势

### 2. 个性化健康建议引擎
- 基于 RAG 知识库 + 大语言模型
- 结合用户健康数据、季节天气、体质特征
- 每日生成专属养生方案，含饮食、运动、作息建议

### 3. 亲人关怀守护
- 一键邀请家人加入，健康数据授权共享
- 子女可远程查看父母健康状况，及时发现异常
- 多角色权限管理，保护隐私安全

### 4. 在线问诊服务
- 图文问诊，医生实时接诊
- 健康快照一键发送，医生快速了解患者情况
- 问诊评价体系，保障服务质量

### 5. 三端协同架构
- **用户端**（HarmonyOS App）— 健康管理、AI助手、亲人关怀
- **医生端**（HarmonyOS App）— 工作台、问诊管理、患者管理
- **管理端**（Web）— 用户管理、医生审核、知识库维护

## 技术创新点

| 创新点 | 说明 |
|--------|------|
| HarmonyOS 原生开发 | 基于 ArkTS / ArkUI 开发，充分发挥鸿蒙系统分布式能力 |
| RAG + 中医知识库 | 将传统中医养生知识与现代 RAG 技术结合，提供专业建议 |
| 结构化健康模型 | 10+ 种健康指标统一建模，自动评估与异常预警 |
| 异步 AI 任务编排 | 舌象分析、建议生成采用异步任务模式，用户体验流畅 |
| 细粒度授权体系 | 亲人关怀支持按指标类别授权，兼顾便利与隐私 |

---

## 技术栈

**前端：** HarmonyOS 5.0 / ArkTS / ArkUI / DevEco Studio

**后端：** Spring Boot 3.x / MyBatis / MySQL 8.0

**AI 能力：** RAG 知识库 / 大语言模型 / 舌象视觉分析 / Node.js AI 编排引擎
